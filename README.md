# Jitterx Script

Gestor SSH + BHTTP para VPS. Requiere licencia.

## Instalar (como root)
```bash
wget -qO install.sh https://raw.githubusercontent.com/jittervpn/jitterx-script/main/install.sh && bash install.sh
```
Te pedirá tu key `JX-XXXX-XXXX-XXXX-XXXX`. Sin key válida no se instala nada.
Luego abre el menú con el comando `jitterx`.

Para conseguir una key, contacta al vendedor.
